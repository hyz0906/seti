# SETI 太阳系随机器 (SETI Solar System Randomizer)

> 一款基于浏览器的多人策略桌游引擎 —— 探索太阳系，部署科技，在群星之间书写你的传奇。

---

## 概览

SETI 太阳系随机器是一款回合制策略桌游的数字实现，支持 **1-4 名玩家**（含 AI 对手）。玩家在太阳系棋盘上竞争，通过卡牌、科技、数据扫描和工业公司系统争夺终局最高分。

- **140+ 张卡牌**：三角标效果系统（弃牌 / 扫描 / 收入）
- **4 条科技树**：蓝 / 黄 / 粉 / 通用，带奖励链
- **8 个外星种族**：各具独特面板和差异化机制
- **13 家工业公司**：主动能力 + 被动效果
- **智能 AI 对手**：五层决策架构，支持所有种族策略
- **零依赖**：双击 `index.html` 即可运行

---

## 快速开始

### 运行游戏

1. 克隆或下载本项目
2. 用浏览器打开 `randomizer/index.html`
3. 选择玩家数量、外星种族和随机种子模式
4. 开始游戏

**无需安装任何依赖，无需构建步骤。**

### 系统要求

- 现代浏览器（Chrome / Firefox / Edge 最新版本）
- 屏幕分辨率建议 1920×1080 或更高
- 无需网络连接（离线可用）

## 核心机制

### 游戏流程

1. **设置阶段**：选择玩家数、种族、随机种子
2. **初始牌/公司选择**：每位玩家选择起始手牌和公司
3. **回合循环**（共 5 轮）：
   - 执行主行动（初探 / 环绕 / 登陆 / 扫描 / 研究）
   - 可选快速行动（交易）
   - PASS 后进入收入阶段
4. **终局计分**：5 轮后根据已获取的终局计分公式结算

### AI 系统

五层决策架构实现智能对手：
- **目标推理**：动态分析局面的最优策略方向
- **行动图生成**：枚举候选动作并计算净收益
- **束搜索规划**：在有限搜索宽度内寻找最优行动序列
- **终局估值**：将当前收益投影到终局分数
- **策略选择**：结合对手状态输出最终决策

## 调试功能

游戏内置丰富的调试工具：

- **调试面板**：切换玩家、调整分数、强制收入、获取卡牌
- **双标签日志**：状态日志 + 行动日志（支持 CSV/JSON 导出）
- **作弊模式**：开发测试专用
- **AI 行动简报**：每轮结束自动弹出
- **公共 API**：`window.SetiRandomizer`

## 技术亮点

- **命令模式撤销引擎**：Step 级撤销 + 不可逆屏障
- **能力链系统**：效果合并、分支、多源插入和链式执行
- **确定性随机数**：基于种子可复现，支持每日固定种子
- **策略模式多态**：8 种族 + 13 公司各自独立实现
